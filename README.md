# creative-studio
Claude-студия для креативщика: 56 скиллов (marketingskills + find-skills) и команда агентов: researcher, concept-generator, copywriter, art-director, council-critic, qa-reviewer, brand-guardian.
Использование: открыть репозиторий в Claude Code (или подключить к облачной сессии), заполнить projects/<проект>/brief.md, поставить задачу.
Конвейер: ресёрч, 25-40 идей, отбор советом, производство, контроль (до 3 раундов), сдача.
