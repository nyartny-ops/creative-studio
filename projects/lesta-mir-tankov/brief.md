# Бриф: Мир танков (Lesta), сценарные заходы для UGC-креаторов

- Клиент / продукт: Lesta Games, «Мир танков» (https://lesta.ru/). Задача шире: «бустим игры Лесты», поэтому основной фокус Мир танков, при удачных идеях можно давать масштабирование на Мир кораблей.
- Задача: придумать большое количество сильных сценарных заходов (идей роликов) для контент-креаторов (UGC), чтобы они органично показывали игру.
- Формат результата: презентация в стилистике WILDJAM / «Мир танков. Наша игра» (рабочий док), слайды «Варианты реализации», 6 заходов на слайд. Каждый заход: название, механика ролика с развязкой, чем цепляет досмотр, потенциал виральности / масштабирования, где уместен показ геймплея.
- Аудитория: креаторы (короткие вертикальные видео, стримы, нарезки) и их аудитория: Z и миллениалы, не только хардкорные танкисты. Цель идей: вернуть в игру, привлечь новых, дать контент, который смотрят без интереса к танкам.
- Тон: живой, мемный, самоироничный, абсурдный юмор, русский интернет-контекст. Без канцелярита и штампов.
- Что уже есть в рабочем доке (не повторять, можно усиливать): «Превращаюсь в маленький милый танк» (ИИ-превращение по тренду), «Играю, пока не…», «Аура фарминг», «Тир-лист по вайбу», «Бой с ограничением», «Мир танков, но…».
- Пример подхода (другой проект, SberDevices): креатор в роли, любая бытовая ситуация, интеграция продукта естественным финалом, референс-ролик по клику на название идеи.
- Визуал: тёмные кинематографичные фоны, оранжевые акценты, логотип «Мир танков. Наша игра», шрифт жирный гротеск; стеклянные карточки. Ассеты в references/ (work-cover.png).
- Запреты и ограничения: НЕ ЗАДАНЫ клиентом. Допущения: без политики, реальных военных конфликтов и трагедий, без оскорбления национальностей, без обещаний наград/выигрышей, без упоминания чужих брендов без нужды, рекламная интеграция с маркировкой по закону. Нужно уточнить у пользователя.
- Каналы: ТикТок/Reels/Shorts/VK Клипы/YouTube/Telegram; уточнить приоритетные.
- Сроки, бюджет: не указаны.
- Открытые вопросы: 1) есть ли ограничения Лесты (что нельзя показывать, возраст, насилие); 2) на какие каналы бьём в первую очередь; 3) нужен ли ресурс на Мир кораблей; 4) есть ли референс-ролики, на которые ссылаемся в презентации.
