# 03. Тексты карточек: «Сценарные заходы для креаторов / Варианты реализации»

Дата: 05.11.2026. Вход: brief.md, 02b-shortlist.md, 02-concepts A-E.
Формат карточки: название (до 6 слов) + описание креатора 35-55 слов, 3-4 предложения (что делает креатор, поворот, финал / где геймплей, при необходимости последним предложением «Масштабируется на…»).
Колонка «Служебные пометки» не идёт на слайд. Число слов посчитано вручную, возможна погрешность в 1-2 слова.
Флаг «НА СОГЛАСОВАНИЕ С КЛИЕНТОМ» стоит у идей про монетизацию и самоиронию над брендом: D6, E9, E10.

Общее для всех карточек: реклама с маркировкой по закону, без политики, наград и призов, без чужих брендов. Любая надпись интерфейса, звук и режим из карточки сверяются в клиенте до съёмки.
